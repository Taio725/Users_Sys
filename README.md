Sistema de Registro y Almacenamiento de Datos de Personas

Este proyecto nace de la necesidad de contar con una plataforma centralizada y segura para guardar, gestionar y consultar los datos esenciales de personas. El sistema permite registrar información clave (como nombres, identificaciones, correos y teléfonos), asegurando que los datos se almacenen correctamente en una base de datos y estén accesibles a través de una interfaz web limpia y adaptable.

Características Principales (Features)
Almacenamiento Persistente: Registro seguro de los datos de las personas directamente en una base de datos relacional, evitando la pérdida de información.

Consulta y Listado en Tiempo Real: Visualización organizada de todas las personas registradas en el sistema mediante una tabla dinámica.

Gestión de Datos (CRUD): Funciones integradas para actualizar la información de las personas o eliminarlas del registro cuando sea necesario.

Diseño Responsivo (En Desarrollo): Interfaz adaptándose mediante CSS para que el registro de personas pueda realizarse cómodamente desde computadoras, tablets y teléfonos móviles.
